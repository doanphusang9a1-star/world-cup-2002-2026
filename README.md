# FIFA World Cup 2002–2026

Website fan-made/educational về lịch sử World Cup 2002–2026.

## Cấu trúc

- `index.html` — trang web chính
- `images/wc2002.png` → ảnh World Cup 2002
- `images/wc2006.png` → ảnh World Cup 2006
- `images/wc2010.png` → ảnh World Cup 2010
- `images/wc2014.png` → ảnh World Cup 2014
- `images/wc2018.png` → ảnh World Cup 2018
- `images/wc2022.png` → ảnh World Cup 2022
- `images/wc2026.png` → ảnh World Cup 2026
